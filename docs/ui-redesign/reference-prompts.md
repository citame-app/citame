# Generación de referencias

Modo: herramienta integrada imagegen. Las cuatro propuestas se guardan en `references/`; son guías visuales, no capturas de una interfaz funcional. No se han incorporado sus cifras ni datos ficticios a la aplicación.

Prompt base de las cuatro imágenes:

> Use case: ui-mockup. Asset type: high-fidelity implementation reference board for Sisters of Beauty, an actual single-location beauty salon booking app. Design a coherent, premium yet welcoming editorial beauty interface, grounded warm ivory #fbf8f5, white #ffffff, deep rose #8f3c50, near-black #2c2325, muted warm gray #65585c. Lora-style restrained serif headings and Nunito Sans-style legible functional text. Crisp fine borders, generous equal margins, practical readable density, 44px minimum controls, restrained 8-12px control corners, square editorial photography. Spanish language. No gradients, neon, fake ratings, fabricated testimonials or ornamental dashboard charts. This is functional product UI, not illustration; screens flat front-on, crisp typography, no devices, perspective, shadows around a board or decorative props. Use exact brand name 'Sisters of Beauty'.

Extensiones de cada prompt:

- `public-reference-v1.png`: Show a polished desktop public homepage with a daylight beauty editorial photographic hero above a concise category heading 'Tu salón de belleza', one clear 'Reservar cita' action, a refined service menu with real-format euro prices marked as illustrative design content only in the board margin, plus two smaller mobile views of the same home and the public portfolio empty state. An image-led 3-screen landing page, grounded brand band close, precise nav and an open service price list. Photography is illustrative beauty art, not a claim about actual salon premises. Do not invent addresses or ratings.
- `booking-account-reference-v1.png`: Show four equally prominent UX screens on one landscape board: mobile service selection with selectable rows and a persistent compact summary, desktop appointment date/time selection with a clear step indicator and order summary, mobile appointment review with deposit/consent terms, desktop customer account with upcoming appointment and navigation to rewards, profile and notifications. Exact labels include 'Servicios', 'Profesional', 'Fecha y hora', 'Confirmar', 'Mis citas'. Make booking progress and selected states unmistakable. No fake analytics.
- `admin-calendar-crm-reference-v1.png`: Show three large desktop product screens and one mobile crop: salon overview 'Hoy' with actual task-oriented daily appointment list; wide operational day calendar 'Agenda' with professional columns, hours, clear empty slots and subdued appointment blocks; 'Clientes' directory with searchable table and private client detail drawer; mobile bottom navigation for the same app. All use the same compact white sidebar, single active rose navigation state, uncluttered toolbar, editorial page title, white panels on ivory. Show useful ordinary sample appointment data solely as UI reference.
- `admin-commerce-settings-reference-v1.png`: Show four product screen designs: 'Caja' with receipt line items, payment methods and balance; 'Servicios' editable catalog with service rows and price/duration; 'Informes' with a restrained genuine reporting chart and filters; 'Configuración' with clear grouped settings and tab navigation. Include small consistent treatments for inventory, memberships, client forms, reviews and staff settings. Same white sidebar with rose active state, ivory workspace, precise table rhythm, accessible fields, restrained serif page title, functional Nunito Sans labels. An implementation board, no made-up business performance claims outside example UI.

Las tres ilustraciones editoriales y sus prompts exactos están en `assets.json`. Los WebP de distintos tamaños están en `apps/web/public/images/editorial/`. Se han convertido y reducido con Sharp; sin retoques de contenido. Cabello: portada; manicura: carta de servicios; cuidado de cejas: acceso a la cuenta. No aparecen en el portfolio de trabajos reales.
