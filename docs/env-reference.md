# Environment reference

Every variable the project reads, generated by reading `apps/api/src/config.ts`, `apps/web/server.ts`, `compose.prod.yaml`, `scripts/*.sh` and the desktop client. If you add one, add it here ([CONTRIBUTING](../CONTRIBUTING.md)). A template file (`.env.example`) is intentionally not shipped in the repository; copy the "Minimal production `.env`" block below.

Durations are seconds unless the name says otherwise. Booleans accept `true`/`false` (also `1`/`0`, `yes`/`no`). The API validates everything at start-up and exits with all problems listed.

## Minimal production `.env`

For `compose.prod.yaml` (Compose reads `.env` next to it; keep the file out of git, it is ignored):

```sh
POSTGRES_PASSWORD=<openssl rand -base64 24>
BETTER_AUTH_SECRET=<openssl rand -base64 32>
PUBLIC_URL=https://salon.example
SMTP_URL=smtps://user:password@smtp.example:465
NOTIFY_EMAIL_FROM=Sisters of Beauty <no-reply@salon.example>
# HTTPS through the bundled Caddy (docker compose --profile tls):
SITE_ADDRESS=salon.example
```

## API and worker (`apps/api`)

| Variable                                                 | Default                                  | Notes                                                                                                                                                                            |
| -------------------------------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NODE_ENV`                                               | unset                                    | `production` makes cookies `Secure` and enables the "no verification without email" boot check. Set by the production images.                                                    |
| `PORT`                                                   | `3000`                                   | API listen port.                                                                                                                                                                 |
| `DATABASE_URL`                                           | `postgres://sob:sob@localhost:5432/sob`  | Postgres. Secret (`DATABASE_URL_FILE` supported).                                                                                                                                |
| `VALKEY_URL`                                             | `redis://localhost:6379`                 | Sessions, rate limits, SSE fan-out.                                                                                                                                              |
| `VALKEY_KEY_PREFIX`                                      | `sob:`                                   | Namespace for every Valkey key.                                                                                                                                                  |
| `BETTER_AUTH_SECRET`                                     | none, **required**                       | 32+ characters. Signs sessions and opt-out links, encrypts OAuth signing keys. Secret (`_FILE` supported). Rotation effects: [operations](operations.md#6-secrets-rotation).     |
| `BETTER_AUTH_URL`                                        | `http://localhost:3000`                  | Public base URL. In the production compose it is `PUBLIC_URL` (the web origin). https makes cookies `Secure`.                                                                    |
| `TRUSTED_ORIGINS`                                        | empty                                    | Comma-separated browser origins allowed to send cookies (the web app origin).                                                                                                    |
| `AUTH_REQUIRE_EMAIL_VERIFICATION`                        | `true` (compose.yaml dev: `false`)       | Clients confirm their email before signing in. Production refuses to boot with it on and `NOTIFY_EMAIL_PROVIDER=none`.                                                           |
| `TRUST_PROXY`                                            | `false`                                  | Take the client IP from the last `X-Forwarded-For` entry. `true` only behind a proxy you operate.                                                                                |
| `HTTP_IDLE_TIMEOUT_SECONDS`                              | `30`                                     | Idle connection timeout (0 disables, max 255). `/sync/stream` is exempt: its 15 s heartbeat is longer than Bun's 10 s default.                                                   |
| `HTTP_MAX_BODY_BYTES`                                    | `1048576`                                | Largest request body; bigger ones are answered `413` before the app sees them.                                                                                                   |
| `DB_POOL_MAX`                                            | `10`                                     | Postgres pool size per process (API and worker each).                                                                                                                            |
| `DB_STATEMENT_TIMEOUT_MS`                                | `10000`                                  | Server-side cap per statement; `0` disables. Migrations, the seed script and `bun run maintenance` run without it.                                                               |
| `DB_LOCK_TIMEOUT_MS`                                     | `5000`                                   | How long a statement waits for a lock; `0` disables.                                                                                                                             |
| `DB_IDLE_IN_TRANSACTION_TIMEOUT_MS`                      | `30000`                                  | Ends sessions idle inside an open transaction; `0` disables.                                                                                                                     |
| `METRICS_TOKEN`                                          | unset                                    | Bearer token for `/metrics`, 16+ characters. Unset: only requests that did not come through the public proxy are answered. Secret (`_FILE` supported).                           |
| `SHUTDOWN_GRACE_MS`                                      | `0` (compose: `5000`)                    | `/ready` is 503 for this long after SIGTERM before the listener closes.                                                                                                          |
| `LOG_LEVEL`                                              | info                                     | `silent` mutes the JSON logger (used by tests).                                                                                                                                  |
| `RATE_LIMIT_GLOBAL_MAX` / `_WINDOW_SECONDS`              | `300` / `60`                             | Per client, every route except `/health`.                                                                                                                                        |
| `RATE_LIMIT_AUTH_MAX` / `_WINDOW_SECONDS`                | `10` / `60`                              | Per client, sign-in, sign-up and account-email endpoints.                                                                                                                        |
| `SYNC_STREAM_RATE_LIMIT_MAX` / `_WINDOW_SECONDS`         | `30` / `60`                              | New `/sync/stream` connections per caller.                                                                                                                                       |
| `RATE_LIMIT_OAUTH_MAX` / `_WINDOW_SECONDS`               | `60` / `60`                              | Authorize, token, consent, revoke, introspect.                                                                                                                                   |
| `RATE_LIMIT_OAUTH_REGISTER_MAX` / `_WINDOW_SECONDS`      | `10` / `60`                              | Anonymous dynamic client registration.                                                                                                                                           |
| `RATE_LIMIT_MCP_MAX` / `_WINDOW_SECONDS`                 | `120` / `60`                             | `/mcp` requests.                                                                                                                                                                 |
| `MCP_RESOURCE_URL`                                       | `<BETTER_AUTH_URL>/mcp`                  | Public URL of the MCP endpoint; the OAuth resource and token audience.                                                                                                           |
| `OAUTH_ACCESS_TOKEN_TTL_SECONDS`                         | `900`                                    | JWT access token lifetime.                                                                                                                                                       |
| `OAUTH_REFRESH_TOKEN_TTL_SECONDS`                        | `1209600`                                | Refresh token lifetime (rotated on use).                                                                                                                                         |
| `NOTIFY_WORKER_ENABLED`                                  | `false`                                  | Run the reminder worker inside the API process. The production compose runs a separate `worker` service and sets this to `false` on the API.                                     |
| `NOTIFY_EMAIL_PROVIDER`                                  | `none` (prod compose: `smtp`)            | `none` or `smtp`.                                                                                                                                                                |
| `SMTP_URL`                                               | unset                                    | `smtp://user:pass@host:587` or `smtps://...:465`. Required for `smtp`. Secret (`_FILE` supported).                                                                               |
| `NOTIFY_EMAIL_FROM`                                      | `Sisters of Beauty <no-reply@localhost>` | Sender. Use a domain you control (SPF, DKIM, DMARC).                                                                                                                             |
| `NOTIFY_SMS_PROVIDER`                                    | `none`                                   | `none` or `twilio`. Read the regulatory notes in [notifications](notifications.md).                                                                                              |
| `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM` | unset                                    | All three required for `twilio`. `TWILIO_AUTH_TOKEN` is a secret (`_FILE` supported).                                                                                            |
| `NOTIFY_DEFAULT_LOCALE`                                  | `en`                                     | `en` or `es-AR`, for clients without a stored preference.                                                                                                                        |
| `NOTIFY_PUBLIC_URL`                                      | `BETTER_AUTH_URL`                        | Origin used in emailed links.                                                                                                                                                    |
| `NOTIFY_POLL_INTERVAL_MS`                                | `5000`                                   | Worker idle poll interval (milliseconds).                                                                                                                                        |
| `NOTIFY_BATCH_SIZE`                                      | `10`                                     | Jobs claimed per poll.                                                                                                                                                           |
| `NOTIFY_VISIBILITY_TIMEOUT_SECONDS`                      | `120`                                    | How long a claimed job is invisible to other workers before retry.                                                                                                               |
| `NOTIFY_MAX_ATTEMPTS`                                    | `5`                                      | Attempts before dead letter.                                                                                                                                                     |
| `NOTIFY_BACKOFF_BASE_SECONDS` / `_MAX_SECONDS`           | `30` / `3600`                            | Retry backoff.                                                                                                                                                                   |
| `MAINTENANCE_ENABLED`                                    | `true`                                   | Scheduled housekeeping in the worker.                                                                                                                                            |
| `MAINTENANCE_INTERVAL_HOURS`                             | `24`                                     |                                                                                                                                                                                  |
| `SYNC_LOG_RETENTION_DAYS`                                | `30`                                     | Superseded sync rows (tombstones are never purged).                                                                                                                              |
| `REMINDER_RETENTION_DAYS`                                | `90`                                     | Sent, skipped and cancelled reminders.                                                                                                                                           |
| `DEAD_LETTER_RETENTION_DAYS`                             | `180`                                    |                                                                                                                                                                                  |
| `OAUTH_TOKEN_GRACE_DAYS`                                 | `7`                                      | Days after expiry before an OAuth token row is removed.                                                                                                                          |
| `OAUTH_IDLE_CLIENT_DAYS`                                 | `30`                                     | Idle dynamically registered OAuth clients.                                                                                                                                       |
| `<NAME>_FILE`                                            | unset                                    | For `DATABASE_URL`, `BETTER_AUTH_SECRET`, `SMTP_URL`, `TWILIO_AUTH_TOKEN`, `METRICS_TOKEN`: path of a file with the value (Docker or Kubernetes secrets). A plain variable wins. |
| `OWNER_EMAIL`, `OWNER_PASSWORD`, `OWNER_NAME`            | unset                                    | Read only by `bun run bootstrap:owner` (idempotent). Never logged.                                                                                                               |
| `SALON_TIMEZONE`                                         | `America/Argentina/Buenos_Aires`         | **No effect today**: Compose and Turborepo pass it through but nothing reads it. The salon timezone lives in the database (seeded default; owner changes it in Admin, Settings). |

## Web server (`apps/web/server.ts`)

| Variable                   | Default                 | Notes                                                                                                                                                                                       |
| -------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PORT`, `HOST`             | `4173`, `0.0.0.0`       |                                                                                                                                                                                             |
| `API_INTERNAL_URL`         | `http://localhost:3000` | Where the web server reaches the API (proxy and SSR). Read at runtime. Compose: `http://api:3000`.                                                                                          |
| `PUBLIC_URL`               | unset                   | Public origin. An https value enables HSTS and `upgrade-insecure-requests` in the CSP and feeds canonical URLs.                                                                             |
| `WEB_HSTS`                 | unset                   | `true` forces HSTS without an https `PUBLIC_URL`.                                                                                                                                           |
| `WEB_TRUST_PROXY`          | `false`                 | Visitor address from the last `X-Forwarded-For` entry; only behind a proxy you operate. Refused at startup when `WEB_PUBLISH` is not loopback (`WEB_TRUST_PROXY_UNSAFE_OK=true` overrides). |
| `WEB_PUBLISH`              | unset                   | Host binding of the published port; compose passes it so the check above can run.                                                                                                           |
| `WEB_IDLE_TIMEOUT_SECONDS` | `30`                    | Idle connection timeout. `/api/sync/stream` is exempt (its heartbeat is longer than Bun's 10 s default).                                                                                    |
| `WEB_MAX_BODY_BYTES`       | `1048576`               | Largest request body; bigger ones get `413`.                                                                                                                                                |

| Variable                                                                                                                                                                                                      | Default            | Notes                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POSTGRES_PASSWORD`                                                                                                                                                                                           | none, **required** | Also builds `DATABASE_URL` for the services.                                                                                                                                                                                           |
| `BETTER_AUTH_SECRET`                                                                                                                                                                                          | none, **required** | See above.                                                                                                                                                                                                                             |
| `PUBLIC_URL`                                                                                                                                                                                                  | none, **required** | Becomes `BETTER_AUTH_URL`, `TRUSTED_ORIGINS`, `NOTIFY_PUBLIC_URL` and the web `PUBLIC_URL`. No trailing slash.                                                                                                                         |
| `SOB_TAG`                                                                                                                                                                                                     | `local`            | Image tag (`sob-api:<tag>`, `sob-web:<tag>`).                                                                                                                                                                                          |
| `WEB_PUBLISH`                                                                                                                                                                                                 | `127.0.0.1:4173`   | Host binding of the web port.                                                                                                                                                                                                          |
| `SITE_ADDRESS`                                                                                                                                                                                                | `localhost`        | Caddy (`tls` profile): public host name. Certificate-expiry contact: uncomment the `email` block at the top of `docker/Caddyfile`.                                                                                                     |
| `CADDY_HTTP_PORT`, `CADDY_HTTPS_PORT`                                                                                                                                                                         | `80`, `443`        | Caddy host ports.                                                                                                                                                                                                                      |
| `OWNER_EMAIL`, `OWNER_PASSWORD`                                                                                                                                                                               | unset              | Used by the `bootstrap-owner` one-shot (`--profile setup`).                                                                                                                                                                            |
| `AUTH_REQUIRE_EMAIL_VERIFICATION`, `NOTIFY_EMAIL_PROVIDER`, `SMTP_URL`, `NOTIFY_EMAIL_FROM`, `NOTIFY_SMS_PROVIDER`, `TWILIO_*`, `NOTIFY_DEFAULT_LOCALE`, `METRICS_TOKEN`, `WEB_TRUST_PROXY`, `SALON_TIMEZONE` | see above          | Passed through to the services. Other API variables are not forwarded by the compose file: add them to the `api` service's `environment` block (anchor `&api-env`, shared by `worker` and `bootstrap-owner`) if you need to tune them. |
